\################### FRENCH ############################################################################



\# Chicago 1930 - Mod 2026 (HUD, Resolution \& FPS Fix)



Ce mod résout le problème de l'interface minuscule (HUD) sur les écrans modernes (1440p/4K), active le zoom à la molette centré sur la souris, et stabilise le framework à 100 FPS fluides sans saccades.



\## Installation Rapide

1\. Allez dans le dossier de votre jeu (`Steam\\steamapps\\common\\Chicago 1930`).

2\. Renommez le fichier `SDL2.dll` d'origine en `SDL2\_real.dll`.

3\. Téléchargez la dernière version compilée de notre `SDL2.dll` et placez-la dans le dossier avec `chicago\_mod.ini`.
